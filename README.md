# Proyek Website - LABORATORIUM MEDIK DAN SPEKTROSKOPI

## Deskripsi Perubahan

### 1. **Perubahan pada Beranda:**
   - Beranda telah diubah dengan menambahkan beberapa elemen visual baru untuk meningkatkan tampilan dan pengalaman pengguna.

   - Logo Universitas Hasanuddin (Unhas) telah ditambahkan pada bagian navbar website.
